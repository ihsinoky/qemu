# RX62N → RX113 差分表（fork-local 作業文書）

状態: v1（2026-11-05、PMO 作成）。RX113 サポートの実装計画の土台。
方針・基準の採用は PO ゲート。本書は事実の整理と PMO 推奨までを含み、決定は含まない。

## 情報源と信頼度

- RX62N 側: 本リポジトリの実装そのもの（`hw/rx/rx62n.c`、`hw/rx/rx-gdbsim.c`、`include/hw/rx/rx62n.h`、`hw/intc/rx_icu.c`）。
- RX113 側: ルネサス公式製品ページ／型式別属性（FPU 有無・メモリ容量）、および RX113 用公式 iodefine.h（RSK サンプル同梱、HW マニュアル Rev.1.00 準拠の生成ヘッダ）から取得したレジスタ配置アドレスと割り込みベクタ番号。
- **iodefine.h はファミリ共通ヘッダ**である点に注意：ベクタ定義があってもアドレス定義のないモジュールは RX113 には実装されていない（例：SCI8/SCI9 はベクタ 230–237 の定義のみでアドレス定義なし＝未実装として扱う）。
- IPR 割付表と割り込みトリガ種別（レベル／エッジ）は iodefine.h からは導出できない。実装フェーズで RX113 HW マニュアル ICU 章から転記する（要照合リスト参照）。

## サマリ

| 項目 | RX62N（QEMU 実装） | RX113（実チップ） | 影響 |
|---|---|---|---|
| CPU コア | RXv1 | RXv1 | 共通。`target/rx/` は無変更でよい |
| FPU | あり（QEMU の rx62n CPU は softfloat 状態を持つ） | **なし**（全型式で Floating Point Unit = No） | CPU 型の扱いが差分（§1） |
| 最大動作周波数 | 96MHz 級（モデルは PCLK = XTAL×4、最大 50MHz） | 32MHz | クロック前提を流用できない（§2） |
| RAM | 64KB（N7）/ 96KB（N8） @0x00000000 | 32KB / 64KB @0x00000000 | クラス定数の差し替えのみ |
| データフラッシュ | 32KB @0x00100000 | **8KB** @0x00100000 | 同上 |
| コードフラッシュ | 384KB / 512KB、モデルは基底 0xFFF80000 固定 | 128/256/384/512KB、**末尾 0xFFFFFFFF に整列** | 基底はサイズから算出する形が正しい |
| 外部バス | あり（gdbsim は SDRAM を 0x01000000 に配置） | **なし** | マシン定義を流用できない（§5） |
| 割り込み | ベクタ 256 本、RX62N 固有の IPR 表 | 最大ベクタ 249、IPR 表は別物 | ICU は流用可、表は新規転記（§3） |
| モデル化済み周辺 | ICU / CMT×2 / TMR×2 / SCI×1（実装） | 同種モジュールは存在するが配置・配線が異なる | §4 の個別差分参照 |
| RX113 固有の主要モジュール | — | LCDC、CTSU、USB0、S12AD、DAC、MTU、RTC、DTC、ELC 等 | スタブ方針＋LCDC は新規モデル（§4） |

## 1. CPU

- 両者とも RXv1 コアで、`target/rx/` の命令実装は共通に使える。
- 相違は FPU の有無のみ。RX113 向けにコンパイルされたファームは FPU 命令を含まない前提だが、正確なモデルとしては RX113 用 CPU 型で FPU を無効化できるか、実装フェーズで確認する（FIT の初期化コードが FPSW に触れるかも併せて確認）。
- 割り込みモデル（ICU 経由の IRQ/FIR の受け方）は RX62N と同方式でよい。

## 2. メモリマップとクロック

| 領域 | RX62N モデル | RX113 |
|---|---|---|
| RAM | 0x00000000〜（64/96KB） | 0x00000000〜（32/64KB） |
| データフラッシュ | 0x00100000、32KB | 0x00100000、**8KB** |
| コードフラッシュ | 基底 0xFFF80000 固定 | 末尾整列（512KB なら 0xFFE00000〜0xFFFFFFFF） |
| 周辺レジスタ領域 | 0x00080000 台 | 0x00080000 台＋0x000A0000 台（USB/LCDC/CTSU） |
| 外部 CS 領域 | 0x01000000（gdbsim の SDRAM） | 存在しない |

- 型式クラス（抽象 MCU クラス＋型式別クラスで RAM/ROM/DFLASH サイズを持つ）は RX62N のパターンを踏襲する。対象型式の既定は D-003 のとおり **R5F51138（512KB／64KB）** を製品 BOM と照合して確定する。他型式（R5F51135=128KB、R5F51136=256KB、R5F51137=384KB）の RAM 対応は要照合。
- クロック：RX62N モデルは「PCLK = XTAL×4（XTAL 8–14MHz）」を realize に埋め込んでいる。RX113 は最大 32MHz で前提が異なるため、RX113 側 realize で独自に定義する（周辺モデルへ渡す input-freq の決め方を含む）。

## 3. 割り込み（ICU）

- ICU モデル（`hw/intc/rx_icu.c`）自体は流用できる。ただし入力は最大 256 本のまま、**IPR 割付表とレベルトリガ一覧は RX113 専用に新規作成**が必要（RX62N の表は流用不可）。
- モデル化対象モジュールのベクタ番号（iodefine.h の VECT 定義より）：

| モジュール | RX62N（モデル配線） | RX113（実チップ） | 差分 |
|---|---|---|---|
| CMT | 28 から 2ch 連続 | CMT0=28、CMT1=29、CMT2=30、CMT3=31 | 開始は同じ。RX113 は 4ch |
| TMR | 174 から（モデルは 2 ユニット×4 本で配線） | TMR0=174–176、TMR1=177–179、TMR2=180–182、TMR3=183–185（各 CMIA/CMIB/OVI の 3 本） | **本数と構成が違う**。チャネル単位 3 本で配線し直す |
| SCI | 214 から（モデルは ch 順に 4 本ずつ連続と仮定） | SCI2=186–189、SCI0=214–217、SCI1=218–221、SCI5=222–225、SCI6=226–229、SCI12=238–245（各 ERI/RXI/TXI/TEI、SCI12 は SCIX0–3 追加） | **ch 番号順に並んでいない**。ch ごとの表引き配線が必須 |
| ICU SWINT | 27 | 27 | 同じ |
| 外部割り込み IRQ0–7 | （RX62N 表内） | 64–71 | RX113 表で確定 |

- 参考（未モデル化モジュールのベクタ）：USB0=36–38・90、CTSU=60–62、RTC=63・92・93、S12AD=102–103、MTU=114 から。最大ベクタは 249。

## 4. 周辺モジュール

### 4.1 既存モデルが流用できるもの

| モジュール | RX62N モデルの配置 | RX113 の配置 | 必要な変更 |
|---|---|---|---|
| ICU | 0x00087000 | 0x00087000 | アドレス同じ。IPR 表・トリガ一覧の差し替えのみ |
| CMT | 0x00088000 から 2 ユニット（ストライド 0x10） | CMSTR 0x00088000、CMT0 0x00088002、CMT1 0x00088008、CMT2 0x00088012、CMT3 0x00088018 | **レジスタ配置が異なる**（4ch が 1 ブロックに密着）。renesas_cmt のオフセット前提を実装時に検証し、必要なら配置側で吸収 |
| TMR | 0x00088200 から 2 ユニット | TMR0 0x00088200、TMR1 0x00088201、TMR2 0x00088210、TMR3 0x00088211 | アドレス帯は同じ。4ch 分のインスタンス化と §3 の配線変更 |
| SCI | 0x00088240（unit 0 のみ実装） | SCI0 0x0008A000、SCI1 0x0008A020、SCI2 0x0008A040、SCI5 0x0008A0A0、SCI6 0x0008A0C0、SCI12 0x0008B300（ストライド 0x20） | **アドレス帯が全く違う**。実装 ch の選定（製品ファームの使用 ch）と表引き配線が必要。モデルの IRQ 出力順と RX113 のベクタ順（ERI→RXI→TXI→TEI）の対応付けも実装時に確認 |
